# 🎮 MultiModal-GameArchitect

> Built for the Meta AI Developer Hackathon (2026)

MultiModal-GameArchitect is an agentic pipeline that transforms ideas, text prompts, or sketches into playable game prototypes (Game Design Documents, C#/GDScript code controllers, and visual assets) powered by Meta's AI ecosystem.

## 🚀 Key Features Built During the Hackathon
- **GDD Agent (Meta Llama 3):** Generates structured Game Design Documents and mechanics breakdown.
- **Code Generation Engine (Meta Muse Code):** Synthesizes ready-to-use C# (Unity) and GDScript (Godot 4) movement and interaction scripts.
- **Visual Asset Pipeline (Meta Muse Image):** Creates 2D sprites, textures, and concept art tailored to the game's theme.
- **Package Exporter:** Packages scripts, assets, and JSON configs into a ready-to-import `.zip` file.

## 🛠️ Tech Stack
- **Backend:** Python, FastAPI, Meta Model APIs (Llama, Muse Image, Muse Code)
- **Frontend:** React / Next.js
- **Game Engine Targets:** Unity / Godot 4
